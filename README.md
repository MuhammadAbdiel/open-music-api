# OpenMusic API - Belajar Fundamental Aplikasi Back-End

Repository ini digunakan untuk kebutuhan dan submisi proyek tugas pada kelas [Belajar Fundamental Aplikasi Back-End](https://dicoding.com/academies/271) di platform [Dicoding Academy](https://dicoding.com).

Dikerjakan oleh [Muhammad Abdiel Firjatullah](https://github.com/MuhammadAbdiel).

## Tentang Aplikasi

Aplikasi pemutar musik bernama **OpenMusic** menyediakan musik yang berlisensi gratis untuk semua orang.

Aplikasi ini dikembangkan secara berangsur hingga nantinya memiliki berbagai fitur seperti menambahkan, menghapus, mengubah data album dan lagu yang dimasukkan oleh pengguna aplikasi. Kemudian membuat _playlist_, memasukan lagu ke dalam _playlist_, hingga membagikan _playlist_ kepada pengguna lain.

Tugas pengembangan pada aplikasi ini adalah membuat _back-end_ berupa sebuah API (Antarmuka Pemrograman Aplikasi) yang sesuai dengan kriteria tertentu.

## Teknologi

Bahasa pemrograman utama yang digunakan pada proyek ini adalah **JavaScript** dan **SQL**.

Peralatan yang digunakan diantaranya adalah:

- [Node.js](https://nodejs.org)
- [Hapi Framework](https://hapi.dev)
- [PostgreSQL](https://www.postgresql.org)
- [Redis](https://redis.io) / [Memurai](https://memurai.com)
- [RabbitMQ](https://rabbitmq.com)
